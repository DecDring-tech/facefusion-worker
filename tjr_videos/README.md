All 10 are in `videos/` (1080x1920, 30fps, sound baked in). Pipeline scripts are in `pipeline/`.

## The formula (reverse-engineered from the 11 reference posts)

| Beat | What happens | Timing |
|---|---|---|
| Part 1 (bait) | Someone else's flex clip (Jack Doherty, Jake Paul, a cat in an M4, a Rolls at a château…). Caption: **"Where's your ___ / TJR? 😂"** in white TikTok Classic font, two lines, sitting at 58–79% down the frame. Audio is the *quiet intro* of the sound. | 2.7–6.5 s, exactly as long as the sound's intro |
| The cut | Hard cut lands **on the beat drop**. | the drop |
| Part 2 (payoff) | TJR's red Koenigsegg Regera B-roll: Miami skyline pose, night crowd, gas station, red carpet, interior. 4–8 quick shots cut on beats (0.5–1.6 s each). Caption: **"Wrong tax bracket / lil bro"**, "Different tax bracket lil bro", "Where's your Ferrari lil bro?", "It's Red." Same font, same spot. | until the sound ends |

Every reference uses the *same* Regera footage, only the bait and the sound change. Captions are white, no box, faint soft shadow, broken before "TJR? 😂" and before "lil bro".

## How to post so it shows the real track

1. Open your own post that uses the sound (listed in the table), tap the spinning record, tap **Add to Favorites**.
2. Upload the new mp4. Tap **Add sound → Favorites**, pick it.
3. Tap **Volume**: set **Added sound = 0**, **Original sound = 100**. The baked-in audio plays, but the post shows the real sound name and joins that sound's page.
4. Don't trim the added sound. The baked audio starts at 0:00 of that sound, so leaving it untrimmed keeps them lined up if you ever raise the added-sound volume.

### Finishing round 2

1. Save each clip as `round2/new_bait/<number>_<name>.mp4` using the names in `round2/specs_round2.json`
   (for example `round2/new_bait/01_mansion.mp4`).
2. From the `tjr_videos` folder run:
   ```
   SPECS=round2/specs_round2.json python3 pipeline/build.py round2/final
   ```
   Needs `ffmpeg`, `python3` with `pillow`, `librosa` is not needed for building. Any concept whose clip is missing still
   renders with the slate so you can keep previewing.
3. Post with the sound from the table at 0% volume, exactly like round 1.

## Making more

`pipeline/` is self-contained: `assets/clean/` holds the caption-free Regera footage, `assets/sounds/` holds the 8 sounds,
`sounds.json` holds the drop and beat grid for each. Add an entry to a specs file (bait file or built-in bait, two captions,
sound, list of Regera shots, beat steps) and run `build.py`. `clean.py` is the caption stripper used on the source clips.
